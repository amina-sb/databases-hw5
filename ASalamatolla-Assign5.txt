Question 1: How many containers of antibiotics are currently available?

Question 2: Which volunteer(s), if any, have phone numbers that do not start
with the number 2 and whose last name is not Jones?

Output:

Gene Lewin

Explanation:
This filters the volunteer table on three conditions. The phone number has to

Question 3: Which volunteer(s) are working on transporting tasks?

Output:
volunteerName
-------------
George Brewer

Explanation:
This follows volunteer -> assignment -> task -> task_type so each volunteer is
linked to the type of every task they are on, then keeps only rows where the
type is "transporting". DISTINCT means someone on two transporting tasks would
still be listed once. There are two transporting tasks, but only "Transport
packages to airport" has anyone assigned to it.

Question 8: Which volunteers began their assignments in the first half of
2021?

Output:
volunteerName
-------------
Joan Simmons
Chris Jordan

Explanation:
This joins volunteers to their assignments and keeps assignments that started
on or after January 1, 2021 and before July 1, 2021. I used '2021-07-01'
instead of BETWEEN - AND '2021-06-30' because the dates are stored as text
with a time, and '2021-06-30 09:00' sorts after '2021-06-30', so BETWEEN
would miss anything starting on June 30. Assignments with no start time are
NULL and drop out of the comparison. Both volunteers started task 103 on May
1, 2021.

Question 10: Which item(s) (if any) have a total value of exactly $100 in one

Explanation:

Question 11: How many volunteers are assigned to tasks with each different
status? (highest to lowest)

Output:
taskStatus  numVolunteers
----------  -------------
open        4
closed      3
ongoing     2
pending     1

Explanation:
Each assignment is linked to its task and then to the task's status, and the
rows are grouped by status. COUNT(DISTINCT a.volunteerId) counts each
volunteer only once per status. That matters for "closed": Chris Jordan is on
two closed tasks, so a plain COUNT(*) would give 4 instead of 3. The groups
are then sorted by the count, highest first.

Explanation:
This groups the packages by the task that produced them and adds up their

subquery. Task 106 three packages (103 + 102 + 103) weigh 308 in total.

Question 14: Of those items that have been packed, which item (or items) were
touched by fewer than 3 volunteers?

Output:
itemDescription
---------------
can of spam
dried fruit
men's coat
sleeping bag
tent
women's coat

Explanation:
This links each packed item to the packages it is in, then to the task each
package was made for, then to the volunteers assigned to that task. Grouping
by item and counting distinct volunteer IDs gives the number of different
people who handled each item, and HAVING keeps items with fewer than 3.
Assignment is LEFT JOINed so a packed item whose task had no volunteers would
still appear with a count of 0 instead of vanishing. The water bottles like 3
volunteers and baby formula 4 are the packed items that do not qualify.

Question 15: Which packages have a total value of more than 100? (lowest to
highest)

Output:
packageId  packageValue
---------  ------------
6          150.0
2          151.0
4          350.0
10         750.0
5          1420.0

Explanation:
For each package, every item's quantity is multiplied by its value and the
results are added up to get the package's total value. HAVING keeps only
totals above 100 which is package 3 is worth exactly 100, so it is excluded, and
ORDER BY packageValue ASC lists them from lowest to highest.
